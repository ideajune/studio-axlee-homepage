# 🚀 Studio AXLee - 고전환 프리미엄 웹 & 랜딩페이지 맞춤 제작 에이전시

클라이언트에게 신뢰감을 전달하고, 즉각적인 견적 문의(Lead)를 수집하기 위한 **1:1 맞춤형 전문 웹 스튜디오 소개 랜딩페이지**입니다.

---

## 🎯 포지셔닝 포인트 (공장형 찍어내기 탈피)
* **"AI/자동화"라는 표현을 전면 배제**: 클라이언트가 "성의 없이 템플릿만 찍어내는 것 아닌가?"라는 거부감을 느끼지 않도록 문구를 정제했습니다.
* **"린(Lean) 프로세스 & 세일즈 퍼널 기획" 강조**: 납기가 빠른 이유를 불필요한 미팅 거품과 비효율을 걷어낸 '선진화된 개발 아키텍처'로 설득력 있게 설명합니다.
* **매출 전환(Conversion) 중심**: 단순히 예쁜 디자인이 아니라 "문의와 결제를 부르는 구조"임을 증명합니다.

## 📧 고객 문의 대표님 개인 이메일 실시간 수신 설정 (Web3Forms)
고객이 웹사이트에서 **[무료 맞춤 견적서 및 제작 제안 받기]**를 누르면, **대표님의 이메일로 1초 만에 알림이 전송**되도록 세팅되어 있습니다.

### 무료 키 발급 (10초 소요, 완전 무료)
1. [web3forms.com](https://web3forms.com) 접속
2. 첫 화면에 대표님이 알림받으실 **이메일 주소(예: 네이버 또는 지메일)** 입력 후 **[Create Access Key]** 클릭
3. 입력하신 이메일로 즉시 `Access Key (예: a1b2c3d4-xxxx-xxxx)`가 도착합니다.
4. [`index.html`](file:///d:/바이브코딩/1031(홈페이지%20제작)/index.html) 파일을 열고, 599번째 줄 부근의 키를 교체합니다:
   ```html
   <!-- 기존 -->
   <input type="hidden" name="access_key" id="web3forms_key" value="YOUR_ACCESS_KEY_HERE">

   <!-- 교체 후 -->
   <input type="hidden" name="access_key" id="web3forms_key" value="발급받은-키-붙여넣기">
   ```
5. 이제 실제 고객이 폼을 작성하고 버튼을 누르면, 대표님 이메일로 고객 이름, 연락처, 견적 내용이 즉시 배달됩니다!
